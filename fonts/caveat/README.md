# Caveat Medium

Replaces extracted Segoe Script and B52 Regular in all nine diary blocks.
Source: https://github.com/google/fonts/tree/main/ofl/caveat
License: SIL Open Font License 1.1; OFL.txt is included in Android exports.

Caveat-Medium.ttf is a static weight-500 instance of Caveat[wght].ttf,
produced with fontTools.varLib.instancer. Static family/style names are set
to Caveat Medium / Regular; copyright and license metadata are preserved.
Legacy Flash font IDs 2508 and 2511 resolve to Caveat in runtime and tools.
Authored sizes and text-box geometry are retained.

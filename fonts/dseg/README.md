# DSEG7 Classic Regular

Unmodified DSEG7Classic-Regular.ttf from the author's stable v0.46 release:
https://github.com/keshikan/DSEG/releases/tag/v0.46

License: SIL OFL 1.1; DSEG-LICENSE.txt is included in game exports.
Replaces extracted DS Crystal (legacy Flash font ID 2836).
The TV channel caption uses 16 authored pixels and a 3.5-pixel downward
correction to match the former 20-pixel DS Crystal glyph height and placement.

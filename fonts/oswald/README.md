# Oswald Medium

Replaces the extracted GraffitiC1 Medium font in the game, including narrative
text, dialog answers and localized popup bodies. Legacy Flash font ID 2 maps
to this font; original source names are accepted only by migration tools.

Source: https://github.com/google/fonts/tree/main/ofl/oswald
License: SIL Open Font License 1.1 (see OFL.txt; included in game exports).

Oswald-Medium.ttf is a static weight-500 instance of the upstream variable
Oswald[wght].ttf, produced with fontTools.varLib.instancer and updateFontNames.
Cyrillic glyphs and original copyright/license metadata are preserved.
The font is shared by the UI components; the original font size, tint and
shader shadows are retained.

# DejaVu Sans

Неизменённые `DejaVuSans.ttf` и `DejaVuSans-Bold.ttf` из системного пакета DejaVu. Используются для переводимых надписей канала «ВЕСТНИК 24»: обычный и жирный гротеск, похожий на исходное новостное оформление. Полная лицензия и сведения об авторах включены в `LICENSE.txt` и экспорт игры.

# JetBrains Mono NL Regular

Replaces extracted Lucida Console in all nine terminal blocks in episode101.
Unmodified upstream static font without programming ligatures.
Source: https://github.com/JetBrains/JetBrainsMono/blob/19371302b95d218af43299bce79ddbddd0bc364d/fonts/archives/ttf/JetBrainsMonoNL-Regular.ttf
Version: Version 2.305; ttfautohint (v1.8.4.7-5d5b)
License: SIL OFL 1.1; OFL.txt is included in Android exports.
Authored font sizes, positions and line breaks are retained.
Report width is 720 authored pixels (formerly 715); line_spacing is -7
(formerly -4 at 2x runtime scale) to fit the complete third report.

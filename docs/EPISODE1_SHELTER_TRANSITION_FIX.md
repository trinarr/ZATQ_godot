# Финальные страницы первого эпизода

У девяти состояний `forest_shelter_*`, `taxi_shelter_*`, `dorvud_shelter_*` ошибочно стоял `ep1_farm_chase`. Каждый переход создавал новый проигрыватель сцены `OldFarmMov` с фотографией `RunningZombies.jpg`.

Восстановлены оригинальные отдельные клипы: `ForestRun` кадр 6 / `Symbol 2745`, `TaxiMov` кадр 6 / `Symbol 2514`, `Dorvud` кадр 8 / `Symbol 2967`. Все три используют чёрный фон, три остановки на кадрах 5, 10, 15 и последовательное появление описания, записи дневника и даты. Далее — результаты 6, 77, 78 соответственно.

Для каждой страницы добавлены собственные исходные параметры арта, составной фон без PNG и нативные анимации текста. Переход между страницами продолжает тот же исходный клип и не проигрывает лишний выход. Нажатия до исходной остановки блокируются. Идентификаторы сюжетных состояний сохранены: старые сохранения открывают исправленные страницы.

Экспорт анимаций теперь создаёт проигрыватель и для статического фона с анимированным текстом. Очистка экспортируемых частей учитывает ссылки из остальных эпизодов, чтобы не удалять переиспользуемые текстуры.

Проверки: `episode1_shelter_transition_test.gd` — 292 проверки трёх маршрутов, поз/прозрачности текста, ранних нажатий и настоящей погони на ферме; полный тест I — 1000 проверок; анимации I — 19412 проверок. Все прошли. Дополнительно отрисованы три финальные страницы в OpenGL Compatibility.

Патч применяется после `zombie_episode4.patch`; использует общий механизм блокировки вступления, добавленный в нём.

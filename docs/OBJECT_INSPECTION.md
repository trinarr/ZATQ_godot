# Осмотр предмета

Тип сцены `object_inspection` показывает обычный нарративный текст и только выбранную обводку. Она окрашивается в `SKETCH.ACTIVE_COLOR` из `scripts/ui/sketch_highlight.gd`; этот цвет применяется к линии, ореолам и внутреннему свечению. У предмета в этом состоянии нет собственного хотспота. Единственный полноэкранный хотспот выполняет первый ответ сцены и закрывает осмотр.

Телефон: сцена `apartment_phone`, исходная сцена `morning_choice`, обводка `living_phone`, текст-заглушка «ТЕСТ». Существующие нарративные тексты не изменены. Осмотр повторяется при каждом нажатии, введение гостиной заново не показывается. Открытый осмотр сохраняется штатным сейвом как текущая сцена; пауза и продолжение поддерживаются.

В редакторе графа выберите тип «Осмотр предмета», заполните «Исходная сцена», «Обводка предмета» и «Текст». Добавьте один ответ с выходом в исходную сцену. В `data/apartment_preview.json` у предмета назначьте:

```json
"interaction": {"type": "object_inspection", "target": "apartment_phone"}
```

Механизм применяется к предметам гостиной и прихожей, описанным в apartment_preview. Не назначайте ему `narrative_flag`: осмотр закрывается ответом и остаётся доступен для повторного открытия. Для начального описания самой комнаты прежнее правило сюжетной переменной сохраняется.

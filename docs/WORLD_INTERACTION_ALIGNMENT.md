# Совмещение взаимодействия с фоном

На широком экране фон использовал `cover` (max отношения сторон),
а сюжетные подсветки и хитбоксы — `fit` (min отношения сторон).
Проверки формы отдельной маски не обнаруживали это расхождение между слоями.

`WorldInteraction` теперь получает точное преобразование `art_layer`:
общий масштаб и смещение, включая безопасную область устройства.
Сюжетные накладки, области нажатия и пульт с индикатором канала помещаются
в эту систему координат. Пересчёт выполняется при изменении размеров окна.
Составные фоны продолжают заполнять экран; дополнительных чёрных полос нет.

Пауза, нижняя полоса повествования, попапы и меню используют прежнюю систему
UI с вписыванием в безопасную область. Для старых несоставных фонов сохраняется
существующий путь отрисовки. Контуры подсветки и ресурсы арта не меняются.

`world_alignment_test.gd` проверяет четыре размера окна, варианты с отступом
108 px слева, совмещение трансформаций, геометрию подсветок, обработку нажатия
на ключи и расположение паузы. Дополнительно проверены экраны эпизодов I–III,
анимации меню и динамические подсветки.

```bash
godot --headless --path . --script tools/world_alignment_test.gd
```

Патч применяется поверх `zombie_episode1_dynamic_highlights.patch`.

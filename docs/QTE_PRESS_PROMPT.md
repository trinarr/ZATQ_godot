# Локализуемая кнопка «Жми!»

Патч применяется поверх `82f417d` («Чистка ресурсов»):

```sh
git apply --3way zombie_qte_press_localized.patch
```

36 PNG кнопки из `e3_john_23_anim_2`…`37` заменены общим компонентом
`scripts/ui/qte_prompt.gd`. Круг, ободок и метки рисуются средствами Godot;
надпись — отдельным Label со шрифтом Flash `font_1.ttf`. Размер текста
подбирается под подпись. Ключ `ui.qte.press` в `locales/ui.csv` содержит
`Жми!` для ru и `Press!` для en.

Каждый кадр хранит исходную матрицу XFL и прозрачность вместо новой картинки.
Сохранены положение, поворот, масштаб, порядок слоёв и кадры появления/исчезновения.
Область клика остаётся у StoryActivity: временные окна, пауза, счётчик успешных
нажатий, сохранения и исходы QTE не изменены. Декоративная кнопка и её подпись
не перехватывают ввод.

Экспорт Episode III распознаёт Symbol 27 и повторно создаёт описания компонента,
поэтому старые картинки не возвращаются после сборки из FLA. В исходном Symbol 27
кнопка является bitmap-заливкой Bitmap 25.png, а не редактируемым текстовым полем.
Удалены старые растры (2 011 643 байта) и их .import.

Проверки: `tools/qte_prompt_test.gd` — все 41 кадр, матрицы, локали, размеры
подписей, исходные области клика, ввод во всех четырёх окнах и блокировка на паузе.
`episode3_components_test.py/.gd` проверяют новые компоненты вместе с остальным
эпизодом; exporter проверен повторной сборкой кадра из оригинального FLA.

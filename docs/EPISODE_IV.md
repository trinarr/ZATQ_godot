# Эпизод IV. Исход

Перенос оригинальных `Episode4p0`, `Episode4p1`, `Episode4p2`, `GoingAlone`, `JeepGroup`, `AfterJess`, `ToHarlem`, `ToExp` и соответствующих веток `DialogMov` из XFL/ActionScript. Патч рассчитан на проект после `zombie_runtime_optimization.patch`.

## Содержание

- 262 достижимых состояния, 595 блоков графа, 1387 ключей локализации.
- 66 состояний диалогов с Джессикой, Мэттом и Виктором.
- 34 результата: 31 смерть и три успешные концовки — 96, 98, 112.
- Шесть выдаваемых предметов; сохранены условия наличия ножа и количества патронов.
- 93 анимированные сцены с исходными позами, порядком слоёв, цветом и прозрачностью при 19 кадрах/с.
- 13 уникальных контуров активных элементов: общий шейдер красного мигания, без отдельных красных PNG.

## Связь эпизодов

Начало выбирается по последней успешной концовке III, отдельно от списка уже открытых финалов:

| Концовка III | Начало IV |
| --- | --- |
| 64 | Церковь |
| 68 | Лагерь |
| 67 (включая общий финал 73) | Армия, затем лагерь |
| Нет сохранённой концовки | Лагерь |

Поле статистики `last_ending` сохраняется и проверяется при загрузке. Старые сохранения без поля используют последний элемент списка открытых концовок; восстановить из него повторное прохождение уже открытого финала невозможно.

## Общие компоненты

Эпизод использует существующие `NarrativeLayer`, `NarrativeBlock`, `EpisodeTimeline`, `InteractiveHighlight`, `PlayerDialog`, `ItemPopup`, экран результата, меню паузы и рваные кнопки. Каталоги компонентов, анимаций и подсветок обнаруживаются по именам `episode*_*.json`, без ограничения тремя эпизодами.

Вступления, которые во Flash ожидали событие `End`, блокируют сюжетные нажатия до последнего кадра. Обычное вступление можно поставить на паузу. Необратимые анимации смерти блокируют паузу. Выдача предмета показывает явно заданную сцену, как в исходном переходе Flash. Текст остаётся нативным, использует общую подложку и шейдерную тень.

Статические варианты арта, уже покрытые анимацией, исключены из каталога. Текстуры одинаковых примитивов переиспользуются между сценами и эпизодами.

## Особенность оригинала

В `GoingAlone.But4ClickFunc` используется `ResultBad(157 - iType * 22)`. Для достижимого `iType == 2` исходник выдаёт результат 113, хотя его описание относится к следующему эпизоду. Здесь сохранено исходное поведение; это не автоматически исправлялось при переносе.

## Воспроизводимая сборка

Команды выполняются из корня проекта; нужен исходный архив с XFL, ActionScript и `assets/Images`, Pillow, NumPy и Inkscape.

```bash
python3 tools/build_episode4_content.py ORIGINAL.zip --force
python3 tools/build_episode4_components.py ORIGINAL.zip
python3 tools/build_episode23_animations.py ORIGINAL.zip --episode 4
godot --headless --editor --path . --import
```

Порядок обязателен: экспорт компонентов связывает исходные кнопки с контурами, экспорт анимаций удаляет дубли статического арта. `--force` пересоздаёт сюжетный граф и перезаписывает ручные изменения; существующие английские переводы сохраняются.

# Компоненты первого эпизода

Все 127 игровых экранов первого эпизода используют раздельные слои. Арт и
декоративные элементы восстановлены по дочерним объектам исходного XFL;
прямоугольные заливки представлены ColorRect. Повествовательный текст остаётся
в Label, кнопка паузы — отдельный элемент у безопасного края экрана.
Интерактивные силуэты сохраняют исходные маски нажатий. Комнаты, телевизионные
вставки, город, ферма, лес, такси и Дорвуд используют ту же систему компонентов.
Общие окна предмета, выбора, паузы и результата также перенесены, включая их
использование в следующих эпизодах.

`data/episode1_components.json` хранит списки слоёв: тип (`texture` или `panel`),
координаты Flash 800×480, цвет, ресурс и путь исходного объекта. Одинаковые
пиксели переиспользуются; текстуры обрезаны по прозрачности и сохранены в WebP
без потерь в `assets/flash_ui/episode1_components/`. `episode1_brushes.json`
содержит шейдерные плашки. Значки выводятся поверх плашек, текст — отдельно.
Картинки могут сами быть полноэкранными, если это один исходный арт Flash;
текст, пауза и интерактивный интерфейс в них не запекаются.

Фоновая группа компонентов заполняет safe area с пропорциональным cover,
а элементы управления используют равномерный масштаб исходного холста.
Автоматическое затемнение распространяется на обе группы. Полноэкранные
`story_*`, `tv_*`, `layout_bg_*`, `city_*`, `ep1_*` экспорты, заменённые
компонентами либо не используемые игрой, удалены. Активные alpha-маски сохранены.
Архивные JSON/каталоги переноса остаются справочными: их старые названия
изображений не означают, что игра загружает эти PNG.

ID сцен, переходы, последствия выбора, статистика и формат сохранений
сохранены. Из графа первого эпизода убраны только неиспользуемые поля `art`
результатов; оформление результата задаётся общим компонентом.

Пересборка и проверки:

```bash
python tools/build_episode1_components.py original.zip
python tools/clean_episode1_art.py
python tools/episode1_components_test.py
python tools/verify_content.py
python tools/verify_locales.py
godot --headless --path . --script tools/episode1_components_test.gd
godot --headless --path . --script tools/episode1_test.gd
godot --headless --path . --script tools/city_routes_test.gd
```

Очистка по умолчанию выводит кандидатов; `--apply` удаляет только заменённые
или неиспользуемые экспорты, сохраняя живые маски. Сборщик компонентов выполняет
такую очистку после успешного извлечения. Старые команды сборки первого эпизода
делегируют ему работу. После применения дождитесь импорта Godot и пересоберите APK.

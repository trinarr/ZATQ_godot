# Настройки из Hangman 2.0

Источник: присланный `hangman-2.0(8).zip`. База патча: Zombie с восстановленным Flash-интерфейсом и патчем равномерного масштаба ×2.

| Раздел | Результат |
| --- | --- |
| Частота кадров | 60 FPS |
| Рендеринг | Mobile; Windows D3D12; ETC2/ASTC, как в Hangman |
| Экран | 1600×960, landscape; canvas_items + expand; равномерное вписывание и центрирование игрового контейнера |
| Шрифты | MSDF для стандартного шрифта Godot, как в Hangman |
| Физика 3D | Jolt Physics |
| Плагины | GodotAndroidYandexAds с Android AAR и исходником, DevConsole с логированием и открытием четырьмя касаниями в правом верхнем углу в debug |
| Android | Gradle, APK, min SDK 24 / target SDK 35, четыре архитектуры, immersive, edge_to_edge=false, резервное копирование выключено |
| Разрешения Android | Internet, Network State, Vibrate; остальные выключены, как в Hangman |
| Идентичность | Zombie Apocalypse: The Quest; com.trinarr.ZombieApocalypseTheQuest; версия 0.2.0 / код 1 |
| Иконка | Текущая icon.png Zombie; адаптивные слои используют стандартные значения экспортера |
| Реклама | Демо-блоки из настроек; ID реальных блоков Hangman заменены настройками Zombie |

Сохранены Quest, стартовая сцена, графика и сохранения Zombie. Не переносятся словарные автозагрузки, переводы, политики Hangman и токен определения региона: это данные другой игры. Рекламный сервис перенесён, но показ рекламы в сюжетных экранах и интерфейс согласия этим патчем не добавляются. SDK инициализируется только при вызове initialize_after_consent().

Релизные ID задаются в yandex_ads/banner_id, interstitial_id, rewarded_id. Необязательные словари rewarded_placements и interstitial_placements позволяют задавать отдельные блоки для мест показа. Debug использует демо-блоки.

## Android-сборка

Настройки Android SDK и Java — общие настройки редактора на вашем компьютере; они уже должны быть доступны из Hangman. Экспортные шаблоны нужны для установленной версии Godot. В новом проекте один раз выполните Project → Install Android Build Template, поскольку локальный каталог android/ отсутствует в исходном архиве Hangman и генерируется движком. Затем используйте пресет Zombie Apocalypse: The Quest; APK сохраняется в build/ZombieApocalypseTheQuest.apk.

Ключ и пароль релизной подписи не содержались в export_presets.cfg Hangman. Для релизной сборки укажите свой ключ в экспортере; приватные файлы подписи и export_credentials.cfg исключены из Git. Код версии 1 следует изменить перед обновлением уже опубликованного приложения, если у него другой versionCode.

## Проверка

Godot 4.6.1: импорт редактором без ошибок; 25 проверок сюжета/сохранений, 52 проверки UI, 34 проверки масштаба. Дополнительно проверены загрузка всех автозагрузок, демо-ID, Android-пресет и реальная подгонка контейнера после изменения viewport. Android APK и рендеринг D3D12 на Windows в этом окружении не проверялись.

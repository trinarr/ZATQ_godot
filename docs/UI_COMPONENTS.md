# Составное главное меню и выбор эпизодов

Главное меню (звук включён/выключен) и все 12 карточек собираются из отдельных
Control/TextureRect, шейдерных кнопок и нативных Label. Общий фон остаётся в
AdaptiveLandscapeCanvas. Общая рамка карточки, стрелки, закрытие, статистика,
логотип и иллюстрации хранятся отдельно. Один ресурс используется во всех
экранах, где встречается одинаковая деталь.

`data/ui_components.json` описывает части в исходных координатах 800×480:
`texture`, `rect`, `layer` и справочный `source` из Flash. PNG в
`assets/flash_ui/components/` обрезаны по альфа-каналу и экспортированы в 2×.
Названия по хешу пикселей предотвращают дублирование. `background` рисуется
под шейдерными кнопками, `foreground` — поверх них; текст выводится последним.
Подписи и области нажатия сохраняют прежние координаты и ключи локализации.

Полноэкранные `menu*.png`, `selector_*.png`, их `adaptive_*` варианты и
дублирующие полноэкранные слои значков удалены. Файлы в docs — архивные
скриншоты, не игровые ресурсы. Сюжетные графы и сохранения не изменены.

Повторное извлечение частей из восстановленной Flash LIBRARY:

```bash
python tools/ui_components.py /path/to/ZombieApocalypse/LIBRARY
```

`build_localized_ui.py` также собирает компоненты при полном восстановлении UI.
`build_flash_ui.py` и `build_adaptive_ui.py` используют тот же экспортёр для
меню и карточек. Экспортёр сохраняет выбранные кадры, преобразования, прозрачность
и порядок исходных дочерних объектов, затем переиспользует одинаковые текстуры.

Проверки:

```bash
python tools/ui_components_test.py
python tools/ui_components_test.py --baseline a4d93de
python tools/flash_ui_regression_test.py
godot --headless --path . --script tools/ui_components_test.gd
godot --headless --path . --script tools/ui_test.gd
godot --headless --path . --script tools/shader_buttons_test.gd
```

Опция `--baseline` требует исходный коммит в локальном Git и сравнивает
восстановленный растровый слой с прежними составными изображениями.
После применения патча дождитесь импорта новых PNG в Godot и пересоберите APK.

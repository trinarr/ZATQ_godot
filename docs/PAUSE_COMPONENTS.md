# Составное меню паузы

`PauseMenu.tscn` остаётся единым автономным компонентом для всех эпизодов:
он сообщает действия сигналами, а переходами и сохранениями управляет Main.

Из оригинального XFL восстановлены `PauseMov / Symbol 83`, его `Grey / Symbol 82`
и `Butns / Symbol 70`. Барабан, центральная кнопка продолжения и её белая стрелка
выводятся отдельными элементами. Четыре действия — самостоятельные Button
с собственной тенью, красной подложкой на существующем `torn_button.gdshader`
и локализованной Label. Состояния наведения и нажатия независимы.

В оригинале чёрные тени четырёх кнопок уже запечены в `Bitmap 60.png`.
Экспортёр делит этот слой на четыре полосы без перекрытия; собранные вместе
они сохраняют исходное изображение. Старый общий PNG больше не нужен.

Барабан занимает место скрытой кнопки открытия паузы у левого края безопасной
области. Центр кнопки продолжения совпадает с центром стрелки открытия.
При изменении размеров окна весь набор сохраняет относительные позиции.
Появление повторяет шесть кадров Flash при 19 fps, включая небольшой перелёт.
Щелчок по затемнению возобновляет игру. Смена звука меняет только подпись.

Пересборка из оригинального архива:

```bash
python tools/build_pause_components.py original.zip
```

Проверки:

```bash
godot --headless --path . --script tools/pause_menu_test.gd
godot --headless --path . --script tools/shared_menus_test.gd
python tools/episode1_components_test.py
python tools/pause_components_test.py
python tools/flash_ui_regression_test.py
python tools/audit_resources.py
```

Проверено Godot 4.6.1 в headless: 37 проверок составных частей, 149 проверок
общих меню и 110 проверок расположения при изменении экрана. Аудит ресурсов
не нашёл неиспользуемых, отсутствующих файлов или осиротевших import-файлов.
Общий старый `ui_test.gd` останавливается на поиске `Забрать ключи`;
эта же ошибка воспроизводится в исходном `a92c583` до изменений меню.

Патч подготовлен от `a92c583`:

```bash
git apply --check zombie_pause_components.patch
git apply zombie_pause_components.patch
```

Кнопки сверху вниз: «Продолжить», «Звук: Вкл/Выкл», «Начать заново»,
«Выйти в меню». Центральная стрелка также продолжает игру. Выход из
приложения удалён из паузы и главного меню. Тени названы по строкам,
чтобы их исходная геометрия не зависела от назначенного действия.

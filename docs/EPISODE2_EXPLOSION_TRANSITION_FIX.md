# Взрыв у двери больницы

Ветка `e2_hospital_20 → e2_boom_4 → e2_boom_5 → e2_result_35` теперь соответствует `MovBoom(3)` из оригинала.

`OnMovLoad` оригинального класса вызывает `gotoAndStop(4)`. Раньше `e2_boom_4` ссылался на `city_door_explosion`, то есть кадр 1 с `DoorOut.jpg` из первого эпизода. Добавлен отдельный план для кадра 4 (`Symbol 2652:3`, вложенный `Symbol 2649`), воспроизводящий все 21 кадр до исходного события `End` при 19 FPS. Далее используется существующий кадр 5 с `Boom.jpg`. Звук `Explosion` перенесён в `e2_boom_5`, как в оригинальном frame-script.

Пауза во время необратимой смерти заблокирована. Идентификаторы сюжетных состояний и результат 35 сохранены. Взрыв двери первого эпизода не менялся. Новые PNG не потребовались: единственный графический примитив переиспользует существующую текстуру.

Генератор содержания исправлен, чтобы пересборка не возвращала ошибочную сцену. Экспорт анимаций поддерживает `--only`, сохраняя остальные записи и переиспользуемые текстуры. Пересборка исправленного клипа:

```bash
python3 tools/build_episode23_animations.py ORIGINAL.zip --episode 2 --only e2_boom_4
```

Проверки: `episode2_explosion_transition_test.gd` — 39 проверок переходов через реальный UI, исходной длительности, звука, паузы и однократного начисления результата. Полный тест II, анимации II/III, правила паузы и исправленные дневники I прошли. Ссылки на ресурсы и локализацию проверены.

Патч применяется после `zombie_episode1_shelter_transition_fix.patch`.

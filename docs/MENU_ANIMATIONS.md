# Анимации главного меню из Flash

Исходник: XFL из `air.zombieapocalypsethequest-1006002.zip`, 19 fps
(`MainTimeline.as`). `data/menu_animations.json` содержит исходные покадровые
значения, без добавленного сглаживания.

| Элемент | Источник | Поведение |
|---|---|---|
| Логотип | LogoMov, Symbol 132 | 9 кадров: отдельное мерцание четырёх частей, остановка на последнем |
| Справка | InfoMov, Symbol 147 | Падение панели сверху, небольшой перелёт и остановка |
| Выбор эпизодов и тестов | EpisodesMov, Symbol 212 | Короткий въезд на 13 исходных пикселей вниз |

Обе панели в своих скриптах переходят сразу на Flash-кадр 2; Godot начинает
с того же кадра. Кнопки, текст и области нажатия получают одинаковое смещение.
На время появления отключается ввод кнопок и обработка Back/стрелок. После
последнего кадра восстанавливаются исходные параметры ввода.

Логотип использует четыре существующие текстуры из `ui_components.json`.
В справке он остаётся отдельным от движущейся панели и смещается с y=70
на y=140. При закрытии справки и смене звука сохраняется тот же экземпляр.
При возврате из выбора или игры создаётся новый логотип с повторным появлением.
Листание эпизодов обновляет содержимое сразу, как Flash Switcher, без повторного
въезда. У MenuMov и FonMov нет таймлайна появления или фоновой анимации.
Кнопка выхода из приложения остаётся удалённой, включая экспорт подписей.

`menu_logo.gd` и `menu_timeline.gd` автономны; смена экранов освобождает проигрыватели.
Изменение размеров окна масштабирует весь экран, не меняя исходных координат кадров.
Новых растровых ресурсов нет.

Пересборка и проверка по оригиналу:

```bash
python tools/build_menu_animations.py /path/to/XFL/LIBRARY
python tools/menu_animations_source_test.py /path/to/XFL/LIBRARY
godot --headless --path . --script tools/menu_animations_test.gd
```

Патч применяется поверх `zombie_menu_pause_actions.patch`.

# Галочки концовок на экране выбора

Вместо числового счётчика рисуются оригинальные галочки Flash: тёмная для
неоткрытой концовки, белая для открытой. Иконки статистики разделены на `stat_skull.png` и `stat_tick.png`.
Галочка побед и галочки концовок используют один `stat_tick.png`.
Внешняя запечённая тень удалена; детали внутри черепа сохранены.
Тёмное состояние галочки получается через `modulate`, отдельных PNG нет.

`statistic_icon.gd` добавляет два смещённых слоя с общим материалом
`statistic_icon_shadow.gdshader`. Это адаптация Hangman
`hint_icon_extrusion_shadow.gdshader`: вместо синего использован тёмный
нейтральный цвет, глубина тени уменьшена до 1×2 px в системе 1600×960.
Цвет тени не наследует коричневое тонирование передней иконки.

Положение соответствует `Symbol 211.LeftOpt.Tick1/2/3`: (284,284),
(299,284), (314,284); размер каждой галочки 14×17 в координатах Flash.
Текст «Концовки:» остаётся частью исходного оформления.

Порядок из `ResultBad.Summer`:

| Эпизод | Первая | Вторая | Третья |
| --- | --- | --- | --- |
| 1 | 6 | 77 | 78 |
| 2 | 38 | 43 | 47 |
| 3 | 64 | 68 | 67 / 73 |

Используется существующая история `stats_for(episode).endings`.
Сохранения и правила начисления концовок не изменены: 73 уже сохраняется
под общим `ending_id = 67`. Тесты и недоступные эпизоды галочки не рисуют.
Для новых эпизодов без исходной таблицы порядок задают уникальные `ending_id`.

Статичная полоска галочек удалена из составных селекторов; вместо неё
`ending_checks.gd` использует общую текстуру статистики. Генератор `ui_components.py`
скрывает Tick1/2/3, чтобы повторный экспорт не вернул статичную полоску.

Патч подготовлен поверх `757a739` (общие компоненты).
Проверка: `git apply --check zombie_ending_checks.patch`.
Применение: `git apply zombie_ending_checks.patch` из корня проекта.

Разрезание и очистка воспроизводятся `tools/build_statistics_icons.py`.
Исходная полоска доступна в Git на ревизии `6100866`:
`assets/flash_ui/components/part_ad6b91577988ccaf5ef3.png`.
Генератор селектора скрывает старую полоску и добавляет два нативных значка.

Правка иконок применяется после `zombie_ending_checks_reuse.patch`.
Проверки: `statistic_icons_test.gd`, `ending_checks_test.gd`,
`ui_components_test.gd`, `shader_buttons_test.gd`, `ui_components_test.py`.

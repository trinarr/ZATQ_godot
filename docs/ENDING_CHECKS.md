# Галочки концовок на экране выбора

Вместо числового счётчика рисуются оригинальные галочки Flash: тёмная для
неоткрытой концовки, белая для открытой. PNG взяты без изменений из
`Symbol 192`: кадры 1/2, `Bitmap 188.png` / `Bitmap 190.png`.

Положение соответствует `Symbol 211.LeftOpt.Tick1/2/3`: (284,284),
(299,284), (314,284); размер каждой галочки 14×17 в координатах Flash.
Текст «Концовки:» остаётся частью исходного оформления.

Порядок из `ResultBad.Summer`:

| Эпизод | Первая | Вторая | Третья |
| --- | --- | --- | --- |
| 1 | 6 | 77 | 78 |
| 2 | 38 | 43 | 47 |
| 3 | 64 | 68 | 67 / 73 |

Используется существующая история `stats_for(episode).endings`.
Сохранения и правила начисления концовок не изменены: 73 уже сохраняется
под общим `ending_id = 67`. Тесты и недоступные эпизоды галочки не рисуют.
Для новых эпизодов без исходной таблицы порядок задают уникальные `ending_id`.

Статичная полоска галочек удалена из составных селекторов; вместо неё
`ending_checks.gd` рисует отдельные текстуры. Генератор `ui_components.py`
скрывает Tick1/2/3, чтобы повторный экспорт не вернул статичную полоску.

Патч подготовлен поверх `757a739` (общие компоненты).
Проверка: `git apply --check zombie_ending_checks.patch`.
Применение: `git apply zombie_ending_checks.patch` из корня проекта.

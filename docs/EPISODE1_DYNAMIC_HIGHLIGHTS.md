# Динамические подсветки первого эпизода

Пятнадцать областей переведены на общий `interactive_highlight.gd`:
силуэты сохраняются в `data/episode1_highlights.json`, красные накладки PNG
не загружаются. Удалены 14 накладок и 8 дублирующих PNG областей нажатия
(426 452 байта самих PNG). Новые данные контуров занимают около 35 КБ.

Контуры восстановлены из альфа-канала оригинальных экспортов с сохранением
отдельных островков и отверстий. Прямоугольная область телевизора остаётся
прямоугольным контуром. Красный цвет взят из преобладающего цвета каждого
исходного ресурса; исключены чёрные растровые каймы.

При первом использовании Godot строит белую SVG-маску в памяти. Маска,
текстура и материал кешируются по идентификатору области. Это внутренний
растровый кеш, а не дополнительные файлы ресурсов. После этого геометрия
не пересчитывается каждый кадр. Подсветка и хит-тест используют один контур;
существующие идентификаторы `ep1_hit_*` в графе не меняются.

Общий шейдер `shaders/interactive_highlight.gdshader` окрашивает маску,
смягчает её край девятью выборками и циклически меняет прозрачность по косинусу.
Период — 1 секунда (цикл оригинала: 19 кадров при 19 fps). Диапазон прозрачности
соответствует исходным состояниям: примерно 0,5–0,8 для обычных областей и
0,6–1 для более ярких. Параметры `period_seconds` и `softness_px` настраиваются
в одном шейдере. Прозрачный запас вокруг контура предотвращает обрезку мягких
краёв. Подсветки не перехватывают ввод, учитывают выбранный арт и наличие ключей.

Нормальные изображения пульта, непрозрачные красные кнопки и заголовки
сохраняются: это арт интерфейса, а не мигающие сюжетные накладки.
Эпизоды II и III остаются на прежней реализации.

Экспортёр `build_episode1_components.py` автоматически запускает миграцию
подсветок. Отдельно её можно повторить командой:

```bash
python tools/build_episode1_highlights.py
```

Проверены 127 экранов и варианты состояний, 1002 проверки сюжетной логики,
144 проверки динамических областей и совпадение силуэтов. Минимальное
пересечение/объединение маски Godot с исходной — 99,8639%.
Проверки выполнены headless, без визуального прогона на устройстве.

```bash
godot --headless --path . --script tools/episode1_highlights_test.gd
python tools/episode1_highlights_source_test.py --baseline-ref <commit-before-migration>
python tools/episode1_components_test.py
python tools/audit_resources.py
```

Патч применяется поверх `zombie_flash_menu_animations.patch`.

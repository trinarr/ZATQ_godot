# Чистка ресурсов

Патч применяется после `zombie_statistics_icons_shader.patch`:

```sh
git apply --3way zombie_unused_resources_cleanup.patch
```

Удалённые бинарные файлы не включены в обратную часть патча. Для их
восстановления используйте исходную ревизию Git; `git apply -R` для этого
патча не предназначен.

Удалены 501 дублирующий WebP (декодированные RGBA сверены с PNG), 62 временных
файла экспорта, старые самостоятельные arrow/close/help и 11 растров вступления,
которые заменены составными экранами. Фон Fon1_1 для выдачи ключей сохранён.
Удалены неиспользуемый ui_fonts.gd и его Roboto Flex с лицензией, а также
осиротевшие .import и метаданные удалённых файлов.

Main больше не загружает старые изображения перед составными экранами.
Неиспользуемое поле image удалено из первого графа и генератора миграции;
архивы переноса сохранены как справочные исходники. Удалена ветка boundary:
проверка verify_content подтверждает, что все эпизоды уже перенесены.

Flash-каталог, исходные карты символов, экспортеры, звуки, маски клика,
анимационные кадры, общие текстуры и используемые плагины сохранены.
Verdana используется экспортером Flash, поэтому его исходный шрифт сохранён.
Временные файлы экспорта добавлены в .gitignore.

Объём арта, звуков и шрифтов без .import: 355,70 → 211,61 МиБ (−40,5%).
Всего удалены 1106 файлов, включая метаданные и неиспользуемый модуль.

Регрессионные тесты обновлены для удалённых архивных image/art и автономной
кнопки продолжения в новом меню паузы.

Проверка после изменений или повторного экспорта:

```sh
python3 tools/audit_resources.py
python3 tools/verify_content.py
python3 tools/verify_locales.py
```

Аудит учитывает составные экраны, вложенные варианты графов, маски,
анимации, звуки, текстовые шрифты и прямые загрузки из scripts.
При добавлении новых способов динамической загрузки нужно расширить аудит.
Он сообщает кандидатов, но сам ничего не удаляет.

# Таблицы переводов

Таблицы находятся в `locales/`:

| Файл | Содержимое |
| --- | --- |
| `ui.csv` | Меню, выбор эпизода, справка, пауза, уведомления, кнопки, подписи результата и активности |
| `episode1.csv` | Название, описание, сцены, варианты состояния, действия и концовки первого эпизода |
| `episode2.csv` | Тексты второго эпизода |
| `episode3.csv` | Тексты третьего эпизода, диалоги, имена говорящих, ответы и пример активностей |

Формат: `key,ru,en`. Русские тексты перенесены из предыдущего состояния проекта. Колонка `en` оставлена пустой для перевода. При отсутствии перевода игра показывает русский источник. Можно добавлять колонки с кодами языков Godot, например `de`, `fr` или `pt_BR`.

Открывайте CSV в редакторе таблиц как UTF-8 с разделителем «запятая». Сохраняйте CSV в UTF-8, сохраняя колонку `key` без изменений. Переносы строк, запятые и кавычки внутри ячейки поддерживаются. Форматные подстановки `%d`, `%s`, `%.1f` и `{version}` нужно сохранять в переводе; их типы и количество должны соответствовать исходнику. Не заменяйте числовые подстановки значениями вручную.

## Редактор сюжета

Редактор **Сюжет → Эпизоды** показывает русский источник вместо ключей. Редактируйте реплики, ответы и параметры эпизода как прежде. Сохранение завершённого графа обновляет соответствующий `episodeN.csv`, сохраняя остальные языковые колонки. Новый эпизод получает собственную таблицу при первом сохранении. Незавершённый граф сохраняется в `.draft`; опубликованные граф и таблица остаются прежними.

В JSON хранятся ссылки вида `@loc:episode3.nodes.e3_john_1.data.text`. Игровые идентификаторы и связи между блоками сохранены. Ключи привязаны к идентификатору блока и пути поля; не переименовывайте блок ради изменения текста. Удалённые ключи остаются в таблице, чтобы случайно не потерять перевод; их можно убрать вручную после проверки ссылок.

Изменения CSV подхватываются после их импорта Godot, при следующем запуске игры или открытии графа. Для русских текстов можно редактировать таблицу напрямую, а затем снова открыть граф в редакторе. Не сохраняйте одновременно старую открытую версию графа после внешнего редактирования CSV.

## Язык игры

Используются штатные `Translation` и `TranslationServer` Godot. При запуске язык выбирается Godot по окружению; русский задан как запасной. Переключение из кода:

```gdscript
TranslationServer.set_locale("en")
```

Открытый игровой экран перерисовывается с переводом. Прогресс, переменные, состояние QTE и пауза сохраняются. Отдельная кнопка выбора языка этим патчем не добавляется.

Штатный импорт CSV сохранён с `compress=0`: это позволяет держать пока пустые языковые колонки без ошибки сжатия пустой таблицы. В редакторе используются CSV, а в собранной игре — штатные импортированные ресурсы `.translation`. Загрузчик автоматически регистрирует их и поддерживает запасное чтение CSV; добавлять ресурсы в Project Settings вручную не требуется. Не подключайте те же таблицы повторно. Файлы `.translation` генерируются Godot и не являются источником текста. CSV включены в Android-экспорт явно.

Подписи ранее запечённые в UI-картинках заменены нативными Label. `data/ui_text_layout.json` содержит ключи и координаты. Красные и серые плашки с рваным краем рисует `shaders/torn_button.gdshader`; их размеры и цвета находятся в `data/ui_brush_layout.json`. Белые значки сохранены в отдельных слоях `*_icons.png`. Подписи кнопок всегда однострочные: размер шрифта уменьшается по фактической ширине и высоте переведённого текста. Название игры в логотипе и текст внутри исходных фотографий остаются частью иллюстраций.

Старые `data/opening.json`, `city_routes.json`, `episode*_routes.json` служат архивом переноса; их строки тоже ссылаются на таблицы, но игра читает канонические графы. `data/flash_catalog.json` — неизменённый справочный архив исходников Flash; его оригинальные строки не являются локалями игры.

## Проверка

```bash
python3 tools/verify_locales.py
python3 tools/verify_content.py
godot --headless --path . --script tools/localization_test.gd
godot --headless --path . --script tools/story_graph_test.gd
```

`tools/extract_locales.py` — одноразовый инструмент миграции старого состояния; повторно его запускать не нужно. Пересборка чистых UI-слоёв из оригинальной Flash LIBRARY: `python3 tools/build_localized_ui.py /path/to/LIBRARY`. Обычная правка переводов не требует пересборки картинок.
